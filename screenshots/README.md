# Product demo screenshots

40 captures at 1568×698, taken against `npm run serve` on 2026-08-31.

## 01-populated/ (28)

A verified member holding the seeded book: six positions across three
vintages and four asset classes, one marked below cost, one realized, one
commitment awaiting ACH.

**No "finish your account setup" banner.** An account with funded positions
has by definition passed the invest gate, so a banner telling it to verify
would contradict the portfolio underneath it. Seeded accounts are now
onboarded as part of the same seam.

## 02-empty/ (7)

The same product with nothing in it: no positions, no votes, no watchlist,
no documents, no profile. The setup banner is present here because it is
true here. Two of these are the good ones for a demo:

- `03-marketplace-gated-teasers` — deals reduced to name, sector, one line
  and artwork, with "Get verified" instead of terms.
- `04-deal-accreditation-required` — the 506(c) gate on a deal page, with
  everything below it blurred.

Reach this state by signing in with any address containing `+new`.
